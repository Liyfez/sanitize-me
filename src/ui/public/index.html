Lossless binary stripping

Direct binary byte manipulation on JPEG APP1/EXIF, PNG ancillary chunks, and WebP RIFF containers. Preserves 100% original pixel data without re-encoding.

AI pre-flight scrubbing

Scrub error logs and config dumps before sharing with ChatGPT or Claude. Redacts API tokens, private keys, JWTs, IPs, and Luhn-validated card numbers.

Zero runtime dependencies

Built using pure Node.js and browser Web API standard libraries. Zero third-party npm supply-chain risk and instant execution.
