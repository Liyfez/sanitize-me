🛡️ Zero-Trace Binary Stripper

Removes APP1/EXIF, GPS coordinates, camera serial numbers, and XMP packets on the byte stream without recompressing image DCT coefficients. 100% pixel fidelity.

🤖 AI Privacy Pre-Flight

Clean error stacks and auth headers before pasting to ChatGPT or Claude. Redacts API tokens, private keys, JWTs, IPs, and local usernames automatically.

🔗 Canonical URL Cleaner

Strips 30+ ad-tech parameters including UTM tags, Facebook clids, YouTube session IDs, and unescapes search engine redirect gateways.
